# Lectionary2002

Latin readings and orations for Mass according to the 2002 Roman Missal, pointed in Gregorian chant notation with GregorioTeX.

**[Browse the readings and orations](https://nojishumpei.github.io/lectionary2002/)**

**[Download the lectern book](books/lectern.pdf)** · **[Download the Gospel book](books/pulpit.pdf)** · [Book build instructions](MAINTENANCE.md#building-book-arrangements)

The catalogue includes the temporal and sanctoral cycles, some votive Masses, and Masses for the Dead.
Gospel readings are provided in the Ancient, Gospel, and ad libitum tones.
The repository contains TeX sources and PDF files.
